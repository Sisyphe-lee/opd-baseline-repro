## 结论

1. **延长训练对 TCOD 有小幅增益（两 run 一致 +3~4），对 adaptive 无益甚至回落（−1/−14）**。
   TCOD 的课程在 ~step58 就完成（窗口=30），此后是纯 OPD，多训即多得；
   adaptive 在 ~step200 后进入 220-234 的振荡带，250 处的高分（230/234/238）
   是振荡上沿的快照，不可通过继续训练兑现。
2. "末段跳变"的最终解释：**adaptive 末段高方差振荡的上尾**，不是可持续增益。
3. 310 步时两方法纠缠在同一带（adaptive 225/220 vs TCOD 228/224）——
   与终点多 seed 结论（p=0.75 等价）互相印证。
4. 对方法叙事的正面含义仍在：adaptive 用自动信号达到了与手工调参课程（η、k_start）
   相同的最终能力，且训练时只保留 ~70-80% 的 turn（trainer 计算量更低）；
   负面含义：其末段不稳定性（σ≈10.5 的终点分布）需要 v2 的稳定化机制
   （checkpoint 平均 / 验证峰值选点 / 末段 lr 衰减等）才能兑现均值。
