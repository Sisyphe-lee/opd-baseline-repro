# adaptive seed45 (206/274) 失败机制分析（2026-08-17）

结论：**未找到可提前识别的失败信号**；seed45 是末段（v200-250）退化的真实低抽样。

证据链：
1. resume 无损判别：崩溃前 step220 checkpoint 评 207/274 ≈ 续跑后 step250 的 206。
2. 课程画像无差别：seed42(230)/43(234)/45(206) 的熵触发率与 loss 保留率逐段几乎一致
   （末期 trig 13-17%，kept 77-87%）。"课程未完成"假说被否证。
   注：合作者 README 的 4.69% 触发率是不同口径的单点值，不能与 50 步分箱直接比。
3. 训练期 rollout 成功率：三 run 到 v200 重合（77-79%），末段分叉——
   seed43 升至 87%（对应终点跳变），seed45 降至 71%（对应低终点）。
4. 反向 KL 与教师熵末段均无异常（seed45 的 KL 反而最低）。

含义：
- adaptive 的**末段（最后 ~50 步）是高方差区**：可以向上（+10~15 的"跳变"，已见 3 例）
  也可以向下（−6，本例）。"末段跳变是系统性机制"的说法降级为"末段高方差、期望为正"。
- 对方法叙事：终点单点比较在此方差下每臂需要 n≈10+；或改用后期均值/曲线级指标；
  或在方法上引入末段稳定化（如末段 checkpoint 平均、早停在验证峰值等——属 v2 议题）。
- seed46/47（fresh，158 在跑）将补充末段行为样本。
